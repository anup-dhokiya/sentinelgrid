How to Integrate SentinelGrid on External Sites & Applications Download TXT Guide

3-Step Integration Workflow

SentinelGrid operates seamlessly via Nginx Reverse Proxy, Python ASGI Middleware, or Node.js Express Middleware without changing your database or application architecture.

Step 1: Point your site's proxy/middleware to SentinelGrid:
Endpoint: http://localhost:8000/v1/inspect

Step 2: Inspect requests in-line (< 1.5ms budget):
If SentinelGrid returns action: "BLOCK", return HTTP 403 Forbidden.
If SentinelGrid returns action: "ALLOW", pass the request to your backend.

Step 3: Access Full Detailed Instructions:
Read the dedicated documentation file located at: /run/media/anup/D/sentinelgrid/docs/HOW_TO_SETUP_ON_OTHER_SITES.txt
