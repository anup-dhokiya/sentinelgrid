Zero-Downtime Integration Architecture

SentinelGrid inspects requests in-line with a < 0.4ms latency budget. Connect any site via Nginx Reverse Proxy, Python ASGI Middleware, Node.js Express, or Go reverse proxy.

Option A: Nginx Reverse Proxy

Use auth_request or proxy_pass to validate requests before passing to upstream.

location /api/ {
    auth_request /_sentinel_check;
    proxy_pass http://upstream_app;
}
location = /_sentinel_check {
    internal;
    proxy_pass http://127.0.0.1:8000/v1/inspect;
    proxy_pass_request_body on;
}

Option B: Python ASGI Middleware

Drop-in middleware for FastAPI, Starlette, or Django ASGI applications.

from sentinelgrid.middleware import SentinelGridMiddleware

app = FastAPI()
app.add_middleware(
    SentinelGridMiddleware,
    control_plane_url="http://127.0.0.1:8000",
    fail_open=False
)
